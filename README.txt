SAMSON MWAURA - BIRTHDAY SURPRISE WEBSITE

FILES
- index.html: webpage content
- style.css: black-and-gold design
- script.js: surprise and music buttons
- brother.jpg: the photo you uploaded

TO ADD BACKGROUND MUSIC
1. Choose an MP3 audio file that you have permission to use.
2. Copy it into this same folder.
3. Rename the file exactly: birthday-music.mp3
4. Open index.html in your browser and press "Play birthday music".
Browsers normally require a person to press Play before audio can start.

TO OPEN THE WEBSITE
Double-click index.html, or open the folder in VS Code and use Live Server if installed.
